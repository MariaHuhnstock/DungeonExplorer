
# DungeonExplorerV5

A console-based dungeon crawler RPG developed in C# during my 20-week internship at Buss-IT-Labs.

## About the Project

DungeonExplorerV5 is a dungeon exploration RPG prototype featuring procedurally generated environments, combat, inventory management, and character progression.

The project combines multiple gameplay systems and focuses on modular object-oriented game development.

## Features

- Explore generated dungeon floors
- Reveal and navigate dungeon maps
- Encounter and fight enemies
- Collect loot and rewards
- Manage inventory items
- Equip weapons and armor
- Buy and sell items
- Progress through character levels
- Save and load game progress

## Technologies

- C#
- .NET 10
- Console Application
- Object-Oriented Programming
- Procedural Generation
- Collections
- File I/O

## Getting Started

### Requirements

- .NET 10 SDK
- Visual Studio or another compatible IDE

### Run the Application

Open the solution in Visual Studio or navigate to the directory containing the `.csproj` file and execute:

```bash
dotnet run
```
